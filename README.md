# IAdashems

Proyecto de la AI Game Jam.

## Trazabilidad del uso de IA

El registro de logs está **separado por integrante** para que cada miembro suba
sus entradas sin pisar los de los demás:

- **Índice:** [logs/INDICE_LOGS.md](logs/INDICE_LOGS.md) (generado, no editar a mano)
- **Detalle:** [AI_TRACE.md](AI_TRACE.md)

```bash
# Regenerar el índice después de agregar tu entrada
python tools/indice_logs.py
```
